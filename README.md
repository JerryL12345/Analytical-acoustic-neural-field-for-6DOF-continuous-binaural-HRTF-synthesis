# Analytical-acoustic-neural-field-for-6DOF-continuous-binaural-HRTF-synthesis
Continuous 6-Degree-of-Freedom (6DoF) spatial audio rendering demands high-fidelity Head-Related Transfer Functions (HRTFs). While Implicit Neural Fields (INFs) offer continuous spatial representations, their dense matrix operations impose prohibitive computational overhead and lack physical interpretability. We propose the Analytical Acoustic Neural Field (AANF), a lightweight, fully explicit framework that replaces neural network weights with closed-form algebraic expressions via physically-guided symbolic regression. AANF implements dual-ear independent orthogonal spatial decomposition to capture natural anatomical asymmetries and enforces causality through homomorphic cepstral analysis to eliminate pre-ringing artifacts. Evaluated on the HUTUBS dataset, AANF achieves a state-of-the-art global Log-Spectral Distortion (LSD) of 3.02 dB and an Interaural Time Difference (ITD) error of 0.021 ms. Furthermore, the explicit algebraic representation compresses the model footprint to under 50 KB and accelerates inference latency to 0.02 ms, enabling ultra-low-latency deployment on resource-constrained edge devices.
